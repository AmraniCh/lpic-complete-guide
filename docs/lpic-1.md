# LPIC-1

Exams **101-500** and **102-500**, objectives version 5.0.

Two exams, 60 questions each, 90 minutes each. Pass both to earn the
LPIC-1 certification.

## Where to start

New to LPIC-1? Start at
[101.1 Determine and configure hardware settings](exam-101/101-system-architecture/101.1-hardware-settings.md)
and work down the sidebar in order.

Revising? Use the search box at the top. It keeps working offline once the
page has loaded.
