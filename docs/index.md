## Contributing

Most objectives are still unwritten. Every page marked **help wanted** is
free to claim.

If you are studying for an exam anyway, writing a page is one of the best
ways to actually learn it. Read the [contributor guide](contributing.md)
to get started, and the [style guide](style-guide.md) for how pages are
written here.
