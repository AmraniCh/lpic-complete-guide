# Exam 102-500

The second of the two exams needed for LPIC-1. 60 questions, 90 minutes.

## Topics

| Topic | Objectives | Weight | What it covers |
|---|---|---|---|
| 105 Shells and Shell Scripting | 2 | 8 | Shell environment, writing simple scripts |
| 106 User Interfaces and Desktops | 3 | 4 | X11, desktop environments, accessibility |
| 107 Administrative Tasks | 3 | 12 | Users and groups, cron and at, locales |
| 108 Essential System Services | 4 | 12 | Time, logging, mail basics, printing |
| 109 Networking Fundamentals | 4 | 14 | IP, network config, troubleshooting, DNS |
| 110 Security | 3 | 10 | Security admin, host security, encryption |

Topic 106 is only 4 points across 3 objectives, and much of it is
conceptual. Do not over-invest there.
