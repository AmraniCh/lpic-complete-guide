# 106.2 Graphical desktops

**Weight: 1**

Candidates should be aware of major Linux desktops. Furthermore, candidates should be aware of protocols used to access remote desktop sessions.

**Objectives**

- Awareness of major desktop environments
- Awareness of protocols to access remote desktop sessions

**Terms**

KDE, Gnome, Xfce, X11, XDMCP, VNC, Spice, RDP

### Major desktop environments

A desktop environment bundles a window manager, panels, a file manager and a set of default applications into one consistent experience. The three you should recognize:

| Desktop | Toolkit | Character |
|---|---|---|
| GNOME | GTK | Clean and simple, the default on Fedora, Debian and Ubuntu |
| KDE Plasma | Qt | Feature rich and highly configurable |
| Xfce | GTK | Lightweight, good for older or smaller machines |

For the exam it is enough to know these exist, roughly how they differ, and that a system can have several installed and choose between them at the login screen.

### Protocols for remote desktop sessions

Sometimes you want the whole desktop of another machine, not just one application window. Several protocols do this, each with its own strengths.

- **XDMCP** (X Display Manager Control Protocol) lets an X server ask a remote display manager for a login screen. It is old, unencrypted, and only sensible on a trusted local network.
- **VNC** (Virtual Network Computing) shares a desktop by sending images of the screen and returning your keyboard and mouse. It is cross platform and simple, but plain VNC is unencrypted, so it is usually tunnelled through SSH.
- **RDP** (Remote Desktop Protocol) comes from Windows. On Linux, `xrdp` provides an RDP server and clients like `remmina` connect to it. It handles encryption and is efficient over slow links.
- **Spice** is built for virtual machines. It gives a smooth console to a guest VM, with sound, shared clipboard and USB redirection. It is common with KVM and QEMU.

```
XDMCP  ->  remote login screen over the X protocol (local, unencrypted)
VNC    ->  shares an existing desktop as images (cross platform)
RDP    ->  Windows style remote desktop, xrdp on Linux (encrypted)
Spice  ->  console for virtual machines (KVM/QEMU)
```

### Summary

I only need awareness here, not deep configuration. The three desktop environments I should know are GNOME (GTK, the common default), KDE Plasma (Qt, very configurable) and Xfce (GTK, lightweight), and a machine can offer more than one at the login screen. For reaching a full desktop on another machine I know four protocols: XDMCP serves a remote login screen over X on a trusted LAN, VNC shares a desktop as images across platforms and is usually wrapped in SSH, RDP is the Windows style protocol that `xrdp` brings to Linux, and Spice is aimed at the consoles of virtual machines under KVM or QEMU.
