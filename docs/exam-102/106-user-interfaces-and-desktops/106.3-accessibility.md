# 106.3 Accessibility

Demonstrate knowledge and awareness of accessibility technologies.

**Objectives**

- Basic knowledge of visual settings and themes.
- Basic knowledge of assistive technology.

**Terms**

High Contrast/Large Print Desktop Themes, Screen Reader, Braille Display, Screen Magnifier, On-Screen Keyboard, Sticky/Repeat keys, Slow/Bounce/Toggle keys, Mouse keys, Gestures, Voice recognition

### Visual settings and themes

These help users who can see the screen but need it easier to read.

- **High contrast themes** use strong colour differences so text stands out from the background.
- **Large print themes** increase font and icon size across the desktop.
- A **screen magnifier** zooms into part of the screen and follows the pointer, for users with low vision.

### Assistive technology for output

These help users who cannot rely on the screen at all.

- A **screen reader** speaks the text on screen aloud. `Orca` is the standard screen reader on GNOME.
- A **Braille display** is hardware that raises pins to show text as Braille. A screen reader can drive it alongside or instead of speech.

### Assistive technology for input

These help users who find a standard keyboard or mouse hard to use.

- **On-screen keyboard**: type by clicking keys with a pointer or touch.
- **Sticky keys**: press modifiers like Ctrl and Shift one at a time instead of together.
- **Repeat keys**: control or turn off the automatic repeat when a key is held.
- **Slow keys**: ignore a key until it is held briefly, to filter accidental taps.
- **Bounce keys**: ignore a second quick press of the same key, for hand tremor.
- **Toggle keys**: play a sound when Caps Lock or Num Lock changes.
- **Mouse keys**: move the pointer with the numeric keypad instead of a mouse.
- **Gestures**: trigger actions with touchpad or touchscreen movements.
- **Voice recognition**: control the computer or dictate text by speaking.

### Summary

This objective is awareness only, so I group the technologies by who they help. For users who can see but need clarity there are high contrast and large print themes and a screen magnifier. For users who cannot use the screen there is a screen reader such as Orca, which can also drive a Braille display. For users who struggle with standard input there is a whole family of keyboard aids: sticky, repeat, slow, bounce and toggle keys, plus an on-screen keyboard, mouse keys that move the pointer from the keypad, gestures, and voice recognition. I do not need to configure these in depth, only to know they exist and what each one is for.
